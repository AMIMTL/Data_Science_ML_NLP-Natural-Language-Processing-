# Natural Language Processing in Python

**Course source:** [Maven Analytics - Natural Language Processing in Python](https://mavenanalytics.io/course/natural-language-processing-in-python)

**Instructor:** Maven Analytics  
**Status:** ✅ Completed

## Course Overview
This practical, hands-on course provides a comprehensive overview of essential NLP concepts in Python. It covers both traditional machine learning techniques and modern deep learning/LLM approaches, from text preprocessing to Transformer architectures.

## What You'll Learn

### Foundational Concepts
- History and evolution of NLP (past 70 years, including Transformers)
- Text preprocessing with pandas and spaCy
- Vectorization into Document-Term Matrix (word counts and TF-IDF)

### Traditional NLP (Machine Learning)
- Sentiment Analysis with VADER library
- Text Classification with Naïve Bayes (scikit-learn)
- Topic Modeling with Non-Negative Matrix Factorization (NMF)

### Modern NLP (Deep Learning & LLMs)
- Neural network basics (layers, nodes, weights, activation functions)
- Transformer architecture (embeddings, attention, feed-forward layers)
- Encoder-only vs. decoder-only vs. encoder-decoder models
- Hugging Face transformers library and Model Hub

### Practical Applications Covered
1. Sentiment Analysis
2. Named Entity Recognition (NER)
3. Zero-Shot Classification
4. Text Summarization
5. Text Generation
6. Document Similarity

## Prerequisites
- Basic Python knowledge
- Interest in NLP and LLMs

## Repository Contents
- `/notebooks` - Jupyter notebooks for each NLP technique
- `/data` - Text datasets used in the course
- `/projects` - NLP projects (sentiment analysis, text classification, topic modeling, etc.)
- `/scripts` - Python scripts for preprocessing and modeling

## Key Libraries Used
- pandas & spaCy (preprocessing)
- scikit-learn (Naïve Bayes, NMF)
- VADER (sentiment analysis)
